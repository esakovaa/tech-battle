# Wurzelraum — design drafts

Static design explorations for the Wurzelraum Kiez-finder, exported from the
Design canvas: https://claude.ai/artifact/WxbL8gKgXKfkQRpkuvEuvS

| File | What it is |
|---|---|
| `A-Intake.dc.html`, `A-Results.dc.html` | Option A · Terracotta — blush/orange/rust, Caprasimo + Hanken Grotesk |
| `B-Intake.dc.html`, `B-Results.dc.html` | Option B · Meadow — grey/yellow/black, Gloock + Geist |
| `Main.dc.html`, `Intake-*.dc.html`, `Results-*.dc.html` | v1 first pass (logo, intake and results, desktop + mobile) |
| `canvas.json` | Canvas layout and pages |
| `img/` | Web-sized crops of the photos in `photos/`, one per photo slot |

The `.dc.html` files reference photos by their canvas asset URL (`/_blob/…`);
the matching files are in `img/` (`a-*` for Option A, `b-*` for Option B).
Flat sizes, rents and comparison wording are sample content, not real data.
